Sample bug reports

Search results still appear when input is fewer than 3 characters

Description
When a user searches for mentors by entering fewer than 3 characters (e.g., "qa"), results still appear. The issue also occurs on the mobile website (Infinix Note 40, Android 14, Chrome 131).
Steps to reproduce
  1. Open the website in a browser.
  2. Log in or proceed as Guest.
  3. Enter fewer than 3 characters in the search field (e.g., "qa").
  4. Notice that results still appear.
Expected result
No results are shown, and the system prompts the user to enter more characters.
Actual result
Results still appear even though the input is fewer than 3 characters.
Severity
Major
Priority
High
Environment
Windows 11 64-bit, Chrome 131

System freezes when uploading a profile photo in HEIC format

Description
The application freezes or gets stuck when a user tries to upload a profile photo in an unsupported format (HEIC).
Steps to reproduce
  1. Log in to the application as an active user.
  2. Open the "Edit Profile" menu.
  3. Click the "Upload Photo" button.
  4. Select a .HEIC file.
  5. Click "Save".
Expected result
The system shows an error message that the file format is not supported (e.g., "File format not supported. Use JPG or PNG").
Actual result
The application freezes or gets stuck immediately after the HEIC file is uploaded.
Severity
Major
Priority
Medium
Environment
Web App v1.9.5 (Chrome 124, Windows 11)
